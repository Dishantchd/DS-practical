# DS Practical 1

## Overview
This practical focuses on working with Python libraries such as Pandas and NumPy for data manipulation and numerical operations.

## Objectives
- Import raw data into a Pandas DataFrame.
- Understand the structure of a dataset.
- Convert DataFrame data into NumPy arrays.
- Find the shape, size and dimensions of arrays.
- Perform mathematical operations using NumPy.

## Operations Performed
- Addition
- Subtraction
- Multiplication
- Matrix Inverse
- Transpose
- Matrix Product

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy

## Dataset
Students Performance Dataset.

## Conclusion
This practical helped in understanding data handling using Pandas and numerical computations using NumPy.
